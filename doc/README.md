# Documentation (Spreadsheet Area)

This folder holds curation spreadsheets and data dictionaries used during ontology building.

## Files
- `ontology_data_dictionary.csv` — columns and meanings used across CSV inputs.
- `curation_template_plants.csv` — editable template for plant metadata.
- `curation_template_compounds.csv` — editable template for compound metadata.
- `POPPy.xlsx` — excel spreadsheet containing different data sources

## Tips
- Keep CSVs in UTF‑8, comma‑separated.
- Avoid commas inside cells (or wrap values in quotes).
- Add a `references` column with PMIDs/DOIs as needed.
